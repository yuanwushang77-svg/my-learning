# 第一次提交：Git 的四个核心动作

日期：2026-11-06

## 一句话理解 Git

Git 是给文件夹做"快照"的工具。每次提交（commit）就是给当前所有文件拍一张照片，
以后随时可以翻回任意一张。

## 四个最常用的命令

```bash
git clone <仓库地址>     # 把远程仓库完整复制到本地（只需做一次）
git status               # 看现在有哪些改动还没提交
git add <文件名>          # 把改动放进"待提交区"（想全部加就用 git add .）
git commit -m "说明"      # 拍下快照，说明写得清楚以后才看得懂
git push                 # 把本地快照上传到 GitHub
```

记忆口诀：**改 → 看 → 加 → 拍 → 推**

## 本地（Local）与远程（Remote）的关系

```
你的电脑                      GitHub
my-learning/  ──push──▶  yuanwushang77-svg/my-learning
          ◀──pull───
```

- `commit` 只影响本地，成功后网页上看不到变化
- `push` 之后网页才会更新，这是新手最容易困惑的一点
- 在别的电脑上改过之后，本地要先 `pull` 再改，否则会冲突

## 本次实际执行过的操作

1. 生成 SSH 密钥（`ssh-keygen`），公钥粘贴到 GitHub → 之后推送不再需要密码
2. 配置身份：`user.name` = yuanwushang77-svg，`user.email` = yuanwushang77@gmail.com
3. `git clone` 这个空仓库到本地
4. 写 README 和这份笔记
5. `git add` + `git commit` + `git push` 完成第一次提交
